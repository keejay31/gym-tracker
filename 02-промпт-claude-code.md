Прочитай 00-концепция.md и 01-наука-объём.md в этой папке — это ТЗ. Строим личный трекер тренировок для одного пользователя.

Платформа: PWA для iPhone, ставится на домашний экран через Safari. Хостинг — GitHub Pages. Vanilla JS + HTML + CSS, без фреймворков и сборки. Данные в IndexedDB, полная работа офлайн (service worker), экспорт/импорт JSON через share sheet iOS для бэкапа. Интерфейс на русском, тёмная тема, крупные кнопки: тренировка идёт на телефоне потными руками.

MVP:
1. Локации «Дом» и «Судно», у каждой свой редактируемый список железа.
   Дом: резинки (уровни 1…N), гири 16 и 24 кг, гантели 2×10 кг, упоры для отжиманий, TRX, ролик для пресса, турник — уточняется.
   Судно: вертикальный блок, горизонтальный блок, машина Смита; скамья/гантели/гриф — уточняются.
2. Библиотека упражнений: движение (паттерн) → варианты (движение + снаряд + локация). У варианта тип нагрузки: кг / уровень резинки / уровень TRX / свой вес ±кг. Мышцы с весами: основная 1, вспомогательная 0,5 (дробный учёт подходов). Засей стартовый набор под железо выше и сделай его редактируемым.
3. Настройки: фаза (сброс / набор / поддержание), сколько тренировок в неделю, фулбади.
4. Планировщик: недельный бюджет подходов на мышцу по фазе (цифры в концепции). Тренировки — очередь, а не дни недели. Перед тренировкой: остаток бюджета ÷ оставшиеся тренировки, не больше 10 подходов на мышцу за сессию. Кнопка «на этой неделе осталось N тренировок». Недобор сгорает и не копится.
5. Экран тренировки: подходы предзаполнены планом, отметка одним тапом ✓, правка через степперы ±. После упражнения оценка в 3 кнопки (легко / норм / на пределе). Таймер отдыха стартует автоматически. Экран не гаснет (Wake Lock).
6. Прогрессия по варианту: двойная прогрессия в диапазоне повторов, правила фаз из концепции. Для резинки/TRX/своего веса — повторы → подход → следующий уровень.
7. Раз в неделю: талия (везде) и вес (только дома, необязательно).
8. Минимальная статистика: последние результаты по варианту, подходы на мышцу за неделю против цели, график талии.

Ничего сверх этого: ни калорий, ни аккаунтов, ни соцфункций.

Порядок работы: сначала покажи модель данных и список экранов, дождись моего ок, потом пиши код. В конце дай короткую инструкцию, как выложить на GitHub Pages и поставить на iPhone.
