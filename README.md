# Gym tracker

Личный трекер тренировок: PWA для iPhone, работает офлайн, данные только на телефоне.
Как устроено — [03-модель-и-экраны.md](03-модель-и-экраны.md).

## Что выкладывать

Для работы приложения нужны только эти файлы и папки:

```
index.html
manifest.webmanifest
sw.js
css/
js/
icons/
```

Остальное (`*.md`, `tests/`, `package.json`, `.claude/`) приложению не нужно — можно выложить вместе, оно не мешает.

## Выложить на GitHub Pages

1. На github.com → **New repository** → имя, например `gym-tracker`, тип **Public** (бесплатный Pages работает только с публичными) → Create.
2. В новом репозитории: **Add file → Upload files** → перетащи файлы и папки из списка выше → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сверху появится адрес: `https://<логин>.github.io/gym-tracker/`.

Если удобнее через терминал (репозиторий на GitHub уже создан, пустой):

```bash
git init -b main && git add index.html manifest.webmanifest sw.js css js icons README.md && git commit -m "Gym tracker" && git remote add origin https://github.com/<логин>/gym-tracker.git && git push -u origin main
```

## Поставить на iPhone

1. Открой адрес в **Safari** (не в Chrome — ставить на экран умеет только Safari).
2. **Поделиться** → **На экран «Домой»** → Добавить. Если есть переключатель «Открывать как веб-приложение» — оставь включённым.
3. Запускай **только с иконки**. У приложения с экрана «Домой» своё хранилище, отдельное от вкладки Safari: что записано во вкладке, в приложении не видно.
4. Первый запуск — с интернетом, дальше работает без сети, в том числе в море.

## Обновить приложение

1. Поправь файлы, в `sw.js` подними версию: `const VERSION = 'gym-v2';`.
2. Загрузи изменённые файлы на GitHub тем же способом.
3. На телефоне открой приложение при наличии сети — новая версия подтянется при следующем открытии. Данные при обновлении не трогаются.

## Бэкап

- **Настройки → Экспорт** открывает «Поделиться»: сохрани `gym-tracker-ДАТА.json` в «Файлы» или Google Drive.
- **Настройки → Импорт** — выбери такой файл, он заменит все данные на телефоне.
- Если бэкапа не было больше 14 дней, на главном экране появится напоминание. Удалишь иконку — удалятся и данные, поэтому бэкап обязателен.

## Ограничения iPhone

- Вибрации из веб-приложения нет. Конец отдыха — три сигнала и вспышка экрана. При включённом беззвучном режиме звука не будет, останется вспышка.
- Экран не гаснет во время тренировки (Wake Lock, iOS 18.4 и новее). Если свернуть приложение, таймер продолжит считать, но сигнала в фоне не будет.

## Проверка логики

Только на компьютере, нужен Node.js 22+: `npm test` прогоняет планировщик и прогрессию (`tests/logic.test.js`).
